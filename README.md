# Task 5: Mental Health Support Chatbot

## Objective
Build an empathetic chatbot for emotional wellness support.

## Dataset
Combined Mental Health Dataset

## Model
DistilGPT2

## Techniques Used
- NLP preprocessing
- Fine tuning
- HuggingFace Trainer API
- Text generation

## Features
- Supportive responses
- Emotional tone generation
- Interactive chatbot

## Conclusion
A fine-tuned language model was developed to provide empathetic responses for mental health related conversations.
